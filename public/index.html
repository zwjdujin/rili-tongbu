终端接入说明

① 终端绑定后获得设备 Token，调用 POST /api/sync 推送变更并拉取增量。
② iOS / Windows：在日历应用中「添加订阅的日历」，地址 https://<你的域名>/api/calendar.ics?token=设备Token
③ 华为手机：日历 App 支持通过「订阅日历 / 导入 .ics」接入同一地址。
详细 API 见仓库 README。
